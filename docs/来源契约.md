# 来源契约

成果源使用 GET /oai，返回 OAI-PMH 2.0 命名空间 XML。Identify 声明秒粒度与 persistent 删除；ListSets 提供 teaching 和 industry。ListMetadataFormats 提供 oai_dc、research，后者含完整研究描述。GetRecord 使用 identifier、metadataPrefix；ListRecords/ListIdentifiers 使用 metadataPrefix，可选 set、from、until，日期为 UTC 秒字符串且双端包含。
一页最多两条。resumptionToken 是不透明的续页凭证，续页请求只携带 verb 与 resumptionToken；响应末页有空 token。凭证属于原查询及发布阶段，阶段变化或显式过期后返回 badResumptionToken。completeListSize 是该次响应观察到的匹配数。无匹配返回 noRecordsMatch；不支持格式返回 cannotDisseminateFormat，不代表成果删除。
成果 identifier 在来源内全局稳定。一个成果可属于多个 set；成员移出不发全局删除头。删除头只含 identifier、datestamp、setSpec，status=deleted，在两个格式均可查询。不同格式应保留各自原文，格式说明不是相互替代的文档。
演练阶段0为四份成果；阶段1在同一秒补充p1；阶段2将p1移出teaching但保留industry；阶段3撤回p1并持久保留删除头。管理端可设置 expire=true 令已有token无效。

演练控制：POST /__control 接收JSON stage及上述控制项，GET /__log显示请求观测；它们供资料源演练与来源测试使用，不属于业务资料获取接口，不得用其直接生成采集结果。每次启动是独立状态。GET /health仅检查服务可用性。
